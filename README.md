# SMSBD.Asia Node.js SDK

Official high-speed Node.js SDK for [SMSBD.Asia](https://smsbd.asia) (SMS Pulse) Bulk SMS & OTP Gateway.

## 🚀 Features
- ⚡ 1-3 Second Instant OTP Delivery across all Bangladesh Telcos (GP, Robi, Banglalink, Teletalk)
- 🔒 Masking & Non-Masking routes supported
- 🛠️ Developer-friendly Promise-based async API
